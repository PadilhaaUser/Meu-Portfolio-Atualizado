# Paulo Padilha | Engenharia de Software Full-Stack

Projeto de portfólio moderno construído para exibir excelência técnica, destacando competências de engenharia de software full-stack, desenvolvimento web e APIs robustas.

## 🚀 Arquitetura & Tecnologias
Este ecossistema foi projetado para alta escalabilidade e performance (SPA), focado na identidade técnica "Premium/Cinemática":

*   **Vite + React.js**: Infraestrutura ultra leve para renderização via componentes de ponta.
*   **Tailwind CSS**: Motor de estilização principal do Design System. Grades responsivas, Dark Mode obrigatório de alta fidelidade e UI baseada em grid CSS orgânico, eliminando arquivos pesados de imagem.
*   **Framer Motion**: Engine dedicada para as animações cinematográficas reativas ao Scroll (`whileInView`), garantindo zoom e fluidez em dezenas de elementos por toda a página.

## 📂 Diretórios Essenciais
*   `/public/`: Servidor de ativos estáticos. Contém a imagem de base renderizada (`hero_bg.png`), foto de perfil oficial (`profile.jpg`) e arquivo nativo para requisições de download do `CV.pdf`.
*   `/src/components/`: Central lógica. Toda a jornada do portfólio está dividida em `Hero` puro CSS, `Skills` em cards fluídos e `Projects` com animações seqüenciais.
*   `/index.html`: Porta de entrada da aplicação rodando ícone vetorial configurado na mão via SVG inline Code (Terminal prompt).

## ⚙️ Uso e Execução Local
1.  Certifique-se que você tenha o Node.js v16+ instalado.
2.  Descompacte a pasta ou clone o repositório.
3.  No terminal, abra o diretório raiz e instale os pacotes principais, usando o comando:  
    `npm install`
4.  Suba a infraestrutura de tempo de execução rodando:  
    `npm run dev`
